# Tử Vi Lá Số (tuvi-laso)

Ứng dụng Lập và An Sao Lá Số Tử Vi chuẩn xác, thiết kế theo phong cách mỹ thuật **Cung Đình Hoàng Gia / Giấy Điệp Cổ Truyền** kết hợp tương tác soi chiếu quan hệ Cung Vị (Tam Hợp, Xung Chiếu, Nhị Hợp).

---

## 🌟 Tính năng nổi bật

- **Lập & An sao Lá Số Tử Vi**: Tính toán chuẩn xác Thiên Bàn, 12 Cung Địa Bàn, Chính tinh, Phụ tinh, Tuần Không, Triệt Lộ, Lưu Tứ Hoá, Lưu Thái Tuế...
- **Giao diện Hoàng Gia Cổ Truyền**: Tông màu Giấy Điệp, viền Hoàng Kim, Ấn triện Chu Sa, thẩm mỹ cung đình trang nhã.
- **Tương tác Soi Chiếu Cung Vị**: Nhấp hoặc hover vào bất kỳ cung nào để xem trực quan các mối quan hệ Tam Hợp, Xung Chiếu và Nhị Hợp.
- **Thanh Công Cụ Đa Năng**: Chế độ toàn màn hình, hỗ trợ in ấn xuất bản A4 chuẩn sắc nét.
- **Tab Luận Giải**: Cung cấp góc nhìn phân tích chi tiết Mệnh - Thân, Quan Lộc, Tài Bạch và Đại Vận.

---

## 🚀 Công nghệ sử dụng

- **Core**: React 19 + TypeScript + Vite
- **Routing**: react-router-dom
- **State Management**: zustand
- **Data Fetching**: @tanstack/react-query
- **Styling**: Vanilla CSS Design Tokens (Dark / Light Mode & Hoàng Cung theme)
- **Icons**: lucide-react

---

## 📦 Hướng dẫn cài đặt & chạy cục bộ

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường phát triển (Dev Server)
npm run dev

# Build sản phẩm (Production)
npm run build
```
